# 主的旨意：哥德式大教堂 UI、動畫與配樂 — 設計文件

日期：2026-10-24
前置：v1（米白紙底、「安靜、無動畫」）與 v2（RAG 後端）

## 一、目標

把前端從「安靜的聖經頁」改成有宗教儀式感的哥德式大教堂，加上動畫與即時合成的配樂。
這和 v1 的「安靜、無動畫」刻意相反，但與 v1 的核心理念一致：**外表越像真的，反差越大**。

不做：外部字型或音檔、WebGL、第三方函式庫、後端改動。

## 二、決策

| 項目 | 選擇 |
|---|---|
| 風格 | 哥德式大教堂：深褐近黑背景、金色文字、彩繪玻璃玫瑰窗、斜射光束、漂浮灰塵 |
| 配樂 | Web Audio API 即時合成（管風琴低音、合唱音墊、程式生成大教堂殘響、偶爾鐘聲），無音檔 |
| 發聲時機 | 「進入聖殿」入口畫面；按鈕分「進入聖殿」與「靜默進入」 |
| 依賴 | 無。原生 ES modules，維持零建置 |

## 三、行為

### 入口
全黑畫面、中央微光十字、兩個按鈕。「進入聖殿」：音樂 3 秒內淡入、黑幕向兩側打開、光束展開。「靜默進入」：同樣的視覺，不發聲。入口出現之前主內容不可被讀屏或鍵盤操作到（`inert`）。

### 主畫面
- 背景約 `#0b0907`、暗角；文字金色約 `#d8b45a`，次要文字約 `#a8957a`；襯線體字型堆疊沿用現有，不引入外部字型。
- 頂部玫瑰窗：以 JS 產生的 SVG，緩慢旋轉（約 120 秒一圈）加金色光暈。
- 光束：數道斜向漸層，透明度緩慢起伏。
- 灰塵：Canvas 約 60 顆粒子在光中漂浮；分頁不可見時暫停動畫。
- 標題金色光暈；輸入框金邊發光。

### 問問題
1. 送出：玫瑰窗亮度一閃、金色光環擴散；文字顯示「祈禱中⋯」並呼吸閃動。
2. 揭曉：經文逐字從光中浮現（總長上限約 4.5 秒），接著出處淡入，再約 1.5 秒後才出現「屬靈解讀」（喜劇節奏）；揭曉時一聲遠處鐘響。
3. **危機訊息例外**：後端回 `crisis` 或前端安全閘命中時，不播任何儀式動畫、不響鐘、音樂降為近乎無聲（hush），只顯示靜態的關懷訊息。

### 配樂
- 持續低音（管風琴感）加合唱音墊（多個失諧鋸齒波經母音共振峰濾波），和弦約每 16 秒緩慢轉換，進行為 Dm – Bb – F – C – Dm – Gm – Bb – C 循環。
- 殘響：程式生成約 5 秒的衰減雜訊作為 ConvolverNode 的脈衝響應。
- 總音量上限 0.25；右上角靜音鍵，選擇存於 localStorage（失敗時靜默忽略）。
- 所有音色與時間參數集中在 `audio.js` 最上方的常數，方便調整。

### 無障礙與退路
- `prefers-reduced-motion`：關閉旋轉、灰塵、逐字浮現與光環，只保留淡入；音樂仍只在使用者主動選擇「進入聖殿」時才播。
- 逐字浮現時，完整經文放在 `aria-label`，逐字 `span` 設 `aria-hidden`。
- 沒有 AudioContext 或建立失敗時，音訊模組回傳無作用物件，不丟錯。
- 靜態模式（無後端）與 API 模式行為不變；「存成圖片」卡片改為暗底金字（同色票，不畫玫瑰窗）。

## 四、檔案

| 檔案 | 責任 |
|---|---|
| `index.html` | 入口、靜音鍵、玫瑰窗與灰塵容器、其餘結構維持 |
| `assets/style.css` | 色票、版面、光束、關鍵影格、reduced-motion |
| `assets/sanctuary.js` | 純函式（逐字排程、玫瑰窗 SVG、儀式規則）與 DOM 控制器 |
| `assets/audio.js` | 純函式（和弦、頻率、靜音儲存）與合成引擎 |
| `assets/app.js` | 只加事件掛勾（入口、靜音鍵、ask 流程的 busy／reveal／crisis） |
| `assets/card.js` | 只改色票 |
| `tests/sanctuary.test.js`、`tests/audio.test.js` | 純邏輯與引擎（用假的 AudioContext） |

## 五、驗證

- `node --test`：純函式與引擎（假 AudioContext）；既有 47 項測試不得退步。
- 以無頭 Chrome 截圖檢查入口、主畫面、答案揭曉後、危機訊息四種狀態的版面（`--screenshot --virtual-time-budget`），並確認 console 無錯誤。
- **無法自動驗證**：聲音好不好聽、動畫順不順，須由使用者在瀏覽器實際體驗後回饋，再調整常數。
